# Reworld Game Night

A one-page guide for our Reworld game night: a 60-second pitch, a 5-minute how-to-play video, and a printable cheat sheet.

Live page: https://bfoster1267-ctrl.github.io/reworld/

Fan-made for a private game night from our own copy of Reworld (designed by Wolfgang Kramer and Michael Kiesling, published by Plan B Games / eggertspiele). Not an official product.
